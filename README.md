# 江戸飛脚 — 五街道

江戸時代の飛脚となって、日本橋から街道を走る 3D ゲーム。

いま走れるのは **日本橋を発って江戸の境を抜けるまで** の二区間です。

| 街道 | 区間 | 実延長 | 標高 | 山場 |
|---|---|---|---|---|
| 東海道 | 日本橋 → 品川宿 | 8.17 km | 1.6 – 12.2 m | 芝から先は左手に江戸湾。八ツ山の坂 |
| 甲州道中 | 日本橋 → 内藤新宿 | 8.08 km | 3.0 – 36.3 m | 九段坂（最急 89‰）と江戸城の堀端 |

どちらも史料の **二里（7.85 km）** に対して +3〜4% で収まっています。

## この区間で何をするのか

出立は暮六つの少し前。**江戸の境の大木戸は暮六つ（18:00）に閉じる**ので、
それまでに抜けなければならない。抜けそこねれば明六つまで足止め、その場で終わり。

- 東海道は **高輪大木戸** まで 5.6 km を 30 分で
- 甲州道中は **四谷大木戸** まで 6.7 km を 40 分で（九段坂があるぶん出立が早い）

道中には江戸の街道そのままの障害がある。

| 障害 | 挙動 |
|---|---|
| 大名行列 | 道の端へ寄り、歩みまで緩めれば行き過ごせる。駆け抜ければ咎めを受けて足止め |
| 町人・荷車 | ぶつかれば脚が止まり、息を削られる |
| 坂 | 勾配がそのまま速度と息に効く。九段坂は息の大半を持っていく |
| 大木戸 | 暮六つに閉門 |

右上の**小地図**に現代の地図と現在地が出るので、いま走っているのが東京のどこなのかが分かります。

## リアリティの根拠

| 要素 | 出典・方法 |
|---|---|
| 標高 | 国土地理院 標高タイル（DEM5A 5m メッシュ / 欠測は DEM10B 10m メッシュ） |
| 小地図 | 国土地理院 淡色地図タイル（zoom 15） |
| 街道の線形 | 旧街道の現況路線を手動デジタイズ（`data/routes/`、±30〜40m） |
| 里程 | 実測値。史料の二里と照合して誤差を明記 |
| 街道の幅 | 江戸の大通り十間から宿場の三間へ、名所を境に細る |
| 江戸湾の汀線 | 金杉橋以南で街道のすぐ東。現在の第一京浜より東は近代の埋立地 |
| 刻 | 不定時法。明六つ〜暮六つを六等分（春秋分に近い日として固定） |

勾配はそのまま速度とスタミナ消費に効くので、坂がきついのは「そう設定したから」ではなく
「実際に急だから」になっています。

### 現代の地形との食い違いをどう扱ったか

標高タイルは**現代**の地表面なので、そのままでは江戸期の地形になりません。二段構えで補正しています。

1. **スパイク除去** — 都市部の DEM は掘割・高架・再開発の造成を拾う。
   中央値フィルタ（75m）で突起を落とし、移動平均（225m）でならす。
   峠のような本物の坂は数百 m 以上続くので消えない。
2. **手動補正** — 失われた地形は根拠を書いたうえで戻す。`data/routes/` の `elevationOverrides` に記録。
   - **八ツ山**（東海道）: 鉄道の切通しで丘が削られたため +9m
   - **九段坂**（甲州道中）: 明治以降に切り下げられたため坂上に +5m

打点そのものを直した箇所もあります。品川宿の区間は当初の打点が御殿山の斜面（16〜18m）に
乗っていたため、標高タイルの低地回廊に合わせて東へ寄せ直しました。

## 開発

```bash
npm install
```

街道データと小地図を生成する（標高タイル・地図タイルは `.cache/` に残るので二度目以降は通信しない）:

```bash
npm run build:data
```

ゲームを起動する:

```bash
npm run dev
```

### 街道を足すには

`data/routes/` に JSON を一枚置いて `npm run build:data` を走らせるだけで、
街道選択の一覧に出ます。コード側に街道固有の分岐はありません。

道幅・区間・大名行列の位置は**名所の名前**で書きます。里程はビルド時に解決されるので、
距離を先に知らなくても書けます。

```json
"width":    [{ "at": "日本橋", "m": 17 }, { "at": "品川宿", "m": 6 }],
"sections": [{ "until": "芝口橋", "kind": "machiya", "spacing": 6.5 }],
"processions": [{ "at": "増上寺 大門", "offset": -430, "members": 34 }]
```

名所に `bridge` / `gateway` / `moat` を添えると、橋・門・堀が建ちます。
`kind` は `origin` `bridge` `town` `temple` `castle` `gate` `okido` `kosatsu` `slope` `view` `post`。

## 操作

| キー | 動作 |
|---|---|
| `W` / `↑` | 走る |
| `Shift` | 全力（息の消耗が大きい） |
| `S` / `↓` | 緩める・止まる |
| `A` `D` / `←` `→` | 左右に避ける |
| `Space` | 跳ぶ（人は跳び越せる） |
| `F` | 早駆け（開発・実演用に 5 倍速） |
| `R` | 出立からやり直す |

## 時間の扱い

距離と標高は実測そのままです。遊べる長さに収めるのは**時間の圧縮**だけで行っています。

`TIME_SCALE = 3` のとき、実時間 1 秒がゲーム内 3 秒に相当します。
飛脚の速度はゲーム内秒あたりの実距離で与えてあるので、走破に要する**ゲーム内**時間は
史実どおり（二里を半刻あまり）になり、プレイヤーが座っている実時間だけが 1/3 に縮みます。
通しで走ると、ゲーム内で約 38 分、実時間で約 12 分です。

## 構成

```
data/routes/*.json            手動デジタイズの原本（緯度経度・名所・道幅・区間・補正）
tools/build-route.mjs         標高取得・投影・名所名の解決
tools/build-map.mjs           小地図用に淡色地図タイルを切り出す
tools/capture-plugin.mjs      開発サーバに POST /__capture を生やす（画面確認用・dev のみ）
src/core/route.js             里程 s と横ずれ u で街道上の位置を扱う
src/core/config.js            速度・息・カメラの調整値
src/game/terrain.js           地面・路面・水面（すべて街道から帯状に押し出す）
src/game/townscape.js         沿道の町並み（五つの InstancedMesh にまとめる）
src/game/landmarks.js         名所の造形、橋による路面の迫り上がり、堀
src/game/obstacles.js         通行人と大名行列
src/game/player.js            飛脚の運動と息
src/game/minimap.js           現代地図の小窓
src/game/sky.js               刻に連動する空と陽
src/game/time.js              不定時法
```

描画は 180 前後のドローコール / 約 18 万三角形。八キロ分の町並みを一度に置いても軽い。

## 既知の限界

- 街道の線形は**現況**の旧街道をなぞったもの。迅速測図・江戸切絵図との突合はまだ。
- 沿道の建物は名所以外すべて手続き的生成のダミー。実在の町割ではない。
- 汀線・堀の形は概略の手入力。実測ではない。
- 標高は現代の地表面。八ツ山・九段坂以外の造成・埋立は補正していない。
- 大木戸の門扉は後年には取り払われたが、ここでは暮六つに閉じるものとして扱っている。
- 不定時法の刻の長さを季節で変えていない（春秋分に固定）。
- 一里塚を置いていない。この区間での正確な位置を確認できていないため。
