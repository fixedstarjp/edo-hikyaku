# 江戸飛脚 — 東海道五十七次

江戸時代の飛脚となって、日本橋から大坂・高麗橋までを走る 3D ゲーム。

- **上位レイヤ**（未実装）: 実座標にもとづく道中マップ。宿場・天候・刻・荷を管理する
- **下位レイヤ**: 峠・川越し・関所・市中などを 3D でプレイする区間

現在動くのは **第一区間「日本橋 → 品川宿」（二里 / 実測 8.17 km）** です。

## この区間で何をするのか

出立は **七つ半（およそ 17:30）**。**高輪大木戸は暮六つ（18:00）に閉じる**ので、
四半刻のうちに江戸の南端を抜けなければならない。抜けそこねれば明六つまで足止め、その場で終わり。

道中には江戸の街道そのままの障害がある。

| 障害 | 挙動 |
|---|---|
| 大名行列 | 道の端へ寄り、歩みまで緩めれば行き過ごせる。駆け抜ければ咎めを受けて足止め |
| 町人・荷車 | ぶつかれば脚が止まり、息を削られる |
| 八ツ山の坂 | この区間で唯一の登り。息の三分の二を持っていく |
| 高輪大木戸 | 暮六つに閉門 |

息（スタミナ）は巡航の走りならほぼ保つ。削られるのは全力疾走と上り坂で、
歩けば戻る。二里を走り切るには息の配分がいる。

## リアリティの根拠

| 要素 | 出典・方法 |
|---|---|
| 標高 | 国土地理院 標高タイル（DEM5A 5m メッシュ / 欠測は DEM10B 10m メッシュ） |
| 街道の線形 | 旧東海道の現況路線を手動デジタイズ（`data/`、約 ±30m） |
| 里程 | 実測 8.17 km。史料の二里（7.85 km）に対し +4% |
| 街道の幅 | 江戸の大通り十間から宿場の三間へ、里程に応じて細る |
| 江戸湾の汀線 | 金杉橋以南で街道のすぐ東。現在の第一京浜より東は近代の埋立地 |
| 刻 | 不定時法。明六つ〜暮六つを六等分（春秋分に近い日として固定） |
| 沿道の名所 | 日本橋・京橋・尾張町・芝口橋・増上寺大門・金杉橋・札の辻・高輪大木戸・泉岳寺・八ツ山・品川宿 |

標高プロファイルは実測で **1.6 〜 12.2 m**、最急勾配 **52.7‰**（八ツ山の坂）。
勾配はそのまま速度とスタミナ消費に効くので、坂がきついのは「そう設定したから」ではなく
「実際に急だから」になっています。

### 現代の地形との食い違いをどう扱ったか

標高タイルは**現代**の地表面なので、そのままでは江戸期の地形にならない。二段構えで補正しています。

1. **スパイク除去** — 都市部の DEM は掘割・高架・再開発の造成を拾う。
   中央値フィルタ（75m）で突起を落とし、移動平均（225m）でならす。
   峠のような本物の坂は数百 m 以上続くので消えない。
2. **手動補正** — 失われた地形は根拠を書いたうえで戻す。
   現在は八ツ山のみ（鉄道の切通しで丘が削られているため +9m）。`data/` の `elevationOverrides` に記録。

打点そのものを直した箇所もあります。品川宿の区間は当初の打点が御殿山の斜面（16〜18m）に
乗っていたため、標高タイルの低地回廊に合わせて東へ寄せ直しました。

## 開発

```bash
npm install
```

街道データ（等間隔リサンプル → 標高取得 → 投影 → 距離・勾配プロファイル）を生成する:

```bash
npm run build:route
```

標高タイルは `.cache/dem/` に保存されるので、二度目以降は通信しません。

ゲームを起動する:

```bash
npm run dev
```

## 操作

| キー | 動作 |
|---|---|
| `W` / `↑` | 走る |
| `Shift` | 全力（息の消耗が大きい） |
| `S` / `↓` | 緩める・止まる |
| `A` `D` / `←` `→` | 左右に避ける |
| `Space` | 跳ぶ（人は跳び越せる） |
| `F` | 早駆け（開発・実演用に 5 倍速） |
| `R` | 出立からやり直す |

## 時間の扱い

距離と標高は実測そのままです。遊べる長さに収めるのは**時間の圧縮**だけで行っています。

`TIME_SCALE = 3` のとき、実時間 1 秒がゲーム内 3 秒に相当します。
飛脚の速度はゲーム内秒あたりの実距離で与えてあるので、走破に要する**ゲーム内**時間は
史実どおり（二里を半刻あまり）になり、プレイヤーが座っている実時間だけが 1/3 に縮みます。
通しで走ると、ゲーム内で約 36 分、実時間で約 12 分です。

## 構成

```
data/route-01-*.json          手動デジタイズの原本（緯度経度・名所・汀線・補正）
tools/build-route.mjs         標高取得と投影のパイプライン
tools/capture-plugin.mjs      開発サーバに POST /__capture を生やす（画面確認用・dev のみ）
src/core/route.js             里程 s と横ずれ u で街道上の位置を扱う
src/core/config.js            速度・息・刻・カメラの調整値
src/game/terrain.js           地面・路面・海（すべて街道から帯状に押し出す）
src/game/townscape.js         沿道の町並み（五つの InstancedMesh にまとめる）
src/game/landmarks.js         名所の造形と、橋による路面の迫り上がり
src/game/obstacles.js         通行人と大名行列
src/game/player.js            飛脚の運動と息
src/game/sky.js               刻に連動する空と陽
src/game/time.js              不定時法
```

描画は 36 ドローコール / 約 18 万三角形。八キロ分の町並みを一度に置いても軽い。

## 既知の限界

- 街道の線形は**現況**の旧東海道をなぞったもの。迅速測図・江戸切絵図との突合はまだ。
- 沿道の建物は名所以外すべて手続き的生成のダミー。実在の町割ではない。
- 汀線は概略の手入力。実測ではない。
- 標高は現代の地表面。八ツ山以外の造成・埋立は補正していない。
- 不定時法の刻の長さを季節で変えていない（春秋分に固定）。
- 一里塚を置いていない。この区間での正確な位置を確認できていないため。
