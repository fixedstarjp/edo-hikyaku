# 江戸飛脚 — 東海道五十七次

江戸時代の飛脚となって、日本橋から大坂・高麗橋までを走る 3D ゲーム。

- **上位レイヤ**: 実座標にもとづく道中マップ（宿場・天候・刻・荷）
- **下位レイヤ**: 峠・川越し・関所・市中などを 3D でプレイする区間

現在実装済みなのは **第一区間「日本橋 → 品川宿」（二里 / 約 7.9km）** です。

## リアリティの根拠

| 要素 | 出典 |
|---|---|
| 標高 | 国土地理院 標高タイル（DEM5A / DEM10B） |
| 街道の線形 | 旧東海道の現況路線を手動デジタイズ（`data/`） |
| 里程 | 日本橋〜品川宿 二里（約 7.85km）と照合 |
| 沿道の名所 | 高輪大木戸・札の辻・金杉橋・増上寺大門ほか |

標高は現代の地表面のため、埋立や切土の影響を受けます。江戸期の汀線とは一致しません（下記「既知の限界」参照）。

## 開発

```bash
npm install
```

街道データ（標高プロファイル）を生成する:

```bash
npm run build:route
```

ゲームを起動する:

```bash
npm run dev
```

## 操作

| キー | 動作 |
|---|---|
| `W` / `↑` | 走る |
| `Shift` | 全力疾走（スタミナ消費大） |
| `S` / `↓` | 歩く・止まる |
| `A` `D` / `←` `→` | 左右に避ける |
| `Space` | 跳ぶ |
| `R` | 最初からやり直す |

## 既知の限界

- 標高は**現代**の地表面。芝〜高輪の海側は江戸期には海だった区間を含む。
- 街道の線形は現況の旧東海道をなぞったもので、迅速測図・江戸切絵図との突合はまだ。
- 沿道の建物はランドマーク以外は手続き的生成のダミー。
