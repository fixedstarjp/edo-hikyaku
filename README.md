# 江戸飛脚 — 五街道

江戸時代の飛脚となって、日本橋から街道を走る 3D ゲーム。

いま走れるのは **日本橋を発って江戸の境を抜けるまで**、五街道すべての第一区間です。

| 街道 | 区間 | 実延長 | 史料 | 標高 | 山場 |
|---|---|---|---|---|---|
| 東海道 | 日本橋 → 品川宿 | 8.17 km | 二里 (7.85) | 1.6 – 12.2 m | 芝から先は左手に江戸湾。八ツ山の坂 |
| 甲州道中 | 日本橋 → 内藤新宿 | 8.08 km | 二里 (7.85) | 3.0 – 36.3 m | 九段坂（最急 89‰）と江戸城の堀端 |
| 中山道 | 日本橋 → 板橋宿 | 8.97 km | 二里十丁 (8.95) | 3.9 – 26.7 m | 湯島から本郷台地への登り、本郷の武家地 |
| 日光・奥州道中 | 日本橋 → 千住宿 | 8.11 km | 二里 (7.85) | 0.7 – 4.7 m | 隅田川沿いの下町、浅草寺門前、千住大橋 |

日光・奥州道中は宇都宮まで同じ道なので、この区間はひとつです。

## この区間で何をするのか

出立は暮六つの少し前。**暮六つ（18:00）までに江戸の境を抜けなければならない。**

- 東海道は **高輪大木戸**、甲州道中は **四谷大木戸** が閉門する。閉じられたらその場で終わり
- 中山道と日光道中には大木戸が無いので、**問屋場への継立の刻限**が効く。遅れれば遅参

道中には江戸の街道そのままの障害がある。

| 障害 | 挙動 |
|---|---|
| 大名行列 | 道の端へ寄り、歩みまで緩めれば行き過ごせる。駆け抜ければ咎めを受けて足止め |
| 町人・荷車 | ぶつかれば脚が止まり、息を削られる |
| 坂 | 勾配がそのまま速度と息に効く。九段坂は息の大半を持っていく |
| 大木戸・刻限 | 暮六つ |

右上の**小地図**に現代の地図と現在地が出るので、いま走っているのが東京のどこなのかが分かります。

**横を向けます。** `Q` `E` か右ドラッグで首を振ると、飛脚を軸にカメラが回り込みます。
高輪で左を向けば江戸湾と沖の帆船、千鳥ヶ淵で左を向けば堀の向こうの江戸城の石垣・櫓・天守、
蔵前で右を向けば隅田川と向島の木立、そして西を向けばどこからでも富士が見えます。

首の動きは臨界減衰のばねで動かしています。指数減衰だと「振り出しだけ速くて後は這う」動きになり、
前を向き直る瞬間が急に感じられるためです。ばねなら振り始めと戻り終わりで速度が 0 になります。

**沿道には 73 箇所の名所**があり、通りかかると画面左下に説明の札が出ます。

## リアリティの根拠

| 要素 | 出典・方法 |
|---|---|
| 標高 | 国土地理院 標高タイル（DEM5A 5m メッシュ / 欠測は DEM10B 10m メッシュ） |
| 小地図 | 国土地理院 淡色地図タイル（zoom 15） |
| 街道の線形 | 旧街道の現況路線を手動デジタイズ（`data/routes/`、±30〜40m） |
| 里程 | 実測値。史料と照合して誤差を明記（下表） |
| 街道の幅 | 江戸の大通り十間から宿場の三間へ、名所を境に細る |
| 江戸湾の汀線・隅田川 | 金杉橋以南で街道のすぐ東が海。蔵前〜浅草では東に隅田川 |
| 刻 | 不定時法。明六つ〜暮六つを六等分（春秋分に近い日として固定） |

里程の一致:

| 街道 | 実測 | 史料 | 誤差 |
|---|---|---|---|
| 中山道 | 8.97 km | 8.95 km | +0.2% |
| 甲州道中 | 8.08 km | 7.85 km | +3% |
| 日光・奥州道中 | 8.11 km | 7.85 km | +3% |
| 東海道 | 8.17 km | 7.85 km | +4% |

勾配はそのまま速度とスタミナ消費に効くので、坂がきついのは「そう設定したから」ではなく
「実際に急だから」になっています。

### 現代の地形との食い違いをどう扱ったか

標高タイルは**現代**の地表面なので、そのままでは江戸期の地形になりません。二段構えで補正しています。

1. **スパイク除去** — 都市部の DEM は掘割・高架・再開発の造成を拾う。
   中央値フィルタ（75m）で突起を落とし、移動平均（225m）でならす。
   峠のような本物の坂は数百 m 以上続くので消えない。
2. **手動補正** — 失われた地形は根拠を書いたうえで戻す。`data/routes/` の `elevationOverrides` に記録。
   - **八ツ山**（東海道）: 鉄道の切通しで丘が削られたため +9m
   - **九段坂**（甲州道中）: 明治以降に切り下げられたため坂上に +5m

打点そのものを直した箇所もあります。品川宿の区間は当初の打点が御殿山の斜面（16〜18m）に
乗っていたため、標高タイルの低地回廊に合わせて東へ寄せ直しました。

### 時代設定と、意図的な時代錯誤について

内藤新宿の開設が元禄十一年(1698)なので、この四区間は**元禄以降**の江戸として作っています。

そのうえで、千鳥ヶ淵の対岸に**江戸城の天守を建ててあります。これは史実に反します。**

寛永十五年(1638)に家光が建てた五重の天守は、天守台を含めて約58m、日本で建てられた最大の天守でした。
しかし明暦三年(1657)の大火で焼け落ち、天守台だけが再建されて、天守そのものは幕末まで建て直されていません。
再建を止めたのは四代家綱を補佐した保科正之で、天守より焼けた城下の復興が先だという理由でした。
江戸時代265年のうち、天守が建っていたのは通算で50年ほどしかありません。

元禄の江戸には天守は無い。それを承知のうえで、**姿を見せることを優先して建てています。**
堀からの隔たりも実際より近く詰めてあります。ゲーム内の名所の説明にもその旨を書いてあります。

## 開発

```bash
npm install
npm run build:data   # 街道データと小地図を生成（タイルは .cache/ に残る）
npm run dev
```

### GitHub Pages へ公開する

`.github/workflows/pages.yml` が入っています。`main` に入るたびに組み立てて公開します。

リポジトリ側で一度だけ設定が要ります。

1. GitHub にリポジトリを作り、`main` を push する
2. リポジトリの **Settings → Pages → Build and deployment** で **Source を「GitHub Actions」** にする
3. push すると Actions が走り、`https://<ユーザー名>.github.io/<リポジトリ名>/` に出る

公開先はプロジェクトページ（サブパス）になるので、資産の参照を `/<リポジトリ名>/` から
始める必要があります。仕組みはリポジトリ名から基準パスを作って `PAGES_BASE` として渡すので、
改名しても追随します。手元では未設定なので `/` のまま動きます。

小地図の画像と索引は `import.meta.env.BASE_URL` 経由で読んでいるため、基準パスに自動で追随します。

街道データ（`src/data/*.generated.json`）と小地図（`public/maps/*.png`）は生成済みのものを
リポジトリに入れてあるので、**公開の組み立てで国土地理院へ取りに行くことはありません**。
データを作り直したときだけ、手元で `npm run build:data` を回して結果をコミットしてください。

### 街道を足すには

`data/routes/` に JSON を一枚置いて `npm run build:data` を走らせるだけで、
街道選択の一覧に出ます。コード側に街道固有の分岐はありません。

道幅・区間・大名行列の位置は**名所の名前**で書きます。里程はビルド時に解決されるので、
距離を先に知らなくても書けます。

```json
"width":    [{ "at": "日本橋", "m": 17 }, { "at": "品川宿", "m": 6 }],
"sections": [{ "until": "芝口橋", "kind": "machiya", "spacing": 6.5 }],
"processions": [{ "at": "増上寺 大門", "offset": -430, "members": 34 }]
```

名所に添える設定で造形が決まります。

| 添える設定 | 建つもの |
|---|---|
| `bridge` | 太鼓橋。路面が実際に迫り上がり、下に堀川が通る |
| `gateway` | 門と参道 |
| `moat` | 街道に並走する堀。`castle` を足すと対岸に石垣・多聞・隅櫓 |
| `keep` | 遠くに聳える天守。層塔型の五重櫓を石垣の上に載せる |
| `clearM` / `clearSide` | 沿道を空ける範囲（堀や石垣が町家に隠れないように） |

`kind` は `origin` `bridge` `town` `temple` `castle` `gate` `okido` `kosatsu` `slope` `view` `post`。

`shoreline` に `side` と `riverWidthM` を書くと、水を左右どちらにも置けます。
`riverWidthM` があれば対岸を立ち上げて川に、無ければ水平線まで続く海になります。

## 携帯で遊ぶ

`pointer: coarse` の端末では操作と描画が自動で切り替わります。

**鍵盤が無いので、走るのを既定にしました。** 指を離していても飛脚は走り続けます。
親指でやることは五つだけです。

| 触れる場所 | 動作 |
|---|---|
| 左下の輪 | **倒すほど大きく避ける**／**下へ引いて歩みを緩める**（大名行列を行き過ごすとき） |
| 右下の「◀ 見る ▶」 | 押しているあいだ横を向く。離せば正面へ戻る |
| 右下の「全力」 | 押しているあいだ全力疾走 |
| 右下の「跳」 | 跳ぶ |
| 画面をなぞる | よそ見（釦と同じことができる） |

横移動は倒し具合をそのまま速さにし、二乗で効かせています。半分倒しても四分の一の速さに
しかならないので、軽く触れたくらいでは寄りません。閾値で切り替えると、少し触れた瞬間に
全速で横へ飛んでしまいます。

見どころに差しかかると、**どちらを向けば何が見えるか**を報せます
（「左手に江戸湾。左を向いてみよ」など）。

- 縦持ちでも横持ちでも遊べますが、**横持ちのほうが街道がよく見えます**
- 画素密度は 1.75 倍で頭打ちにし、多重標本化は切っています（画素密度が高いので割に合わない）
- HUD の書き換えは毎コマではなく 15 回/秒に間引き、遠くの大名行列は行列計算ごと止めています。
  この二つで計算は 0.27ms/コマまで下がりました
- 引っ張って再読込・つまんで拡大・二度叩きの拡大は止めてあります
- 住所欄の出入りで高さが変わるので `100dvh` を使い、切り欠きは `env(safe-area-inset-*)` で避けています

同じ LAN の携帯から開くには、開発サーバのアドレスを使ってください（`npm run dev` が Network の
URL を表示します）。

## 時間の扱い

距離と標高は実測そのままです。遊べる長さに収めるのは**時間の圧縮**だけで行っています。

`TIME_SCALE = 3` のとき、実時間 1 秒がゲーム内 3 秒に相当します。
飛脚の速度はゲーム内秒あたりの実距離で与えてあるので、走破に要する**ゲーム内**時間は
史実どおり（二里を半刻あまり）になり、プレイヤーが座っている実時間だけが 1/3 に縮みます。
通しで走ると、ゲーム内で約 35〜40 分、実時間で約 12 分です。

```
src/game/landmarks.js         名所の造形、橋の迫り上がり、堀、城
src/game/distance.js          遠景の稜線と富士（浮世絵の遠山と同じく平らな藍で刷る）
src/game/obstacles.js         通行人と大名行列
src/game/player.js            飛脚の運動と息
src/game/minimap.js           現代地図の小窓
src/game/touch.js             携帯の操作盤（触れる端末でだけ現れる）

```

## 既知の限界

- 街道の線形は**現況**の旧街道をなぞったもの。迅速測図・江戸切絵図との突合はまだ。
- 沿道の建物は名所以外すべて手続き的生成のダミー。実在の町割ではない。
- 汀線・堀・川幅は概略の手入力。実測ではない。
- 標高は現代の地表面。八ツ山・九段坂以外の造成・埋立は補正していない。
- 富士は実際の見かけ（約 2 度）の 2〜3 倍に誇張してある。稜線に埋もれて見えないため。
- **江戸城の天守は史実に反して建ててある**（上記「意図的な時代錯誤」を参照）。堀の幅も実際より狭い。
- 大木戸の門扉は後年には取り払われたが、ここでは暮六つに閉じるものとして扱っている。
- 中山道・日光道中の「継立の刻限」はゲーム上の設定。この区間についての定めを確認したわけではない。
- 不定時法の刻の長さを季節で変えていない（春秋分に固定）。
- 一里塚を置いていない。各区間での正確な位置を確認できていないため。

## 出典

**出典: 国土地理院（標高タイル・地理院タイル）を加工して使用**

<https://maps.gsi.go.jp/development/ichiran.html>

国土地理院コンテンツ利用規約に従い、加工した内容を明記します。

| もとにしたもの | 加工の内容 |
|---|---|
| 標高タイル DEM5A / DEM10B | 街道上の点で標高を取り出し、中央値フィルタ(75m)と移動平均(225m)で平滑化。さらに八ツ山・九段坂の二箇所に手動の補正を加えている（README「現代の地形との食い違い」参照） |
| 淡色地図タイル(zoom 15) | 街道の範囲で切り出して継ぎ合わせ、各色を 9 階調に落として圧縮 |

このゲームの表示は加工後のものであり、国土地理院が作成・公表したものではありません。
